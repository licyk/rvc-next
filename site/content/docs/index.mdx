RVC Next 是 [Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI)（RVC）的一体化重写：**转换**、**实时**变声、人声**分离**、**训练**与**模型**管理，由同一个服务端、同一个网页界面和同一套命令行（`rvc-next`）提供。数值计算部分从原版逐行移植，并用对比测试保证与原版输出一致。

## 能做什么

| 功能 | 说明 | 教程 |
| --- | --- | --- |
| 转换 | 用音色模型转换音频文件或整个文件夹，可先分离人声、再混回伴奏。 | [转换](/docs/guide-convert) |
| 实时变声 | 用服务端所在电脑的声卡实时变声，参数与音色可在运行中切换。 | [实时变声](/docs/guide-live) |
| 人声分离 | 分离人声与伴奏、去混响、和声分离，以及多步串联预设。 | [人声分离](/docs/guide-separate) |
| 训练 | 从数据集到音色模型：切片、音高、特征、训练、索引，改动后只重跑需要的步骤。 | [训练](/docs/guide-train) |
| 模型管理 | 导入、整理音色与索引，下载演示音色、底模、分离模型和所需资源。 | [模型管理](/docs/guide-models) |
