RVC Next is an integrated rewrite of [Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) (RVC): conversion in **Convert**, live voice conversion in **Live**, vocal separation in **Separate**, training in **Train** and model management in **Models**, provided by one server, one web interface and one command line (`rvc-next`). The numerical code is ported line by line from the original, with comparison tests ensuring identical output.

## What it can do

| Feature | Description | Guide |
| --- | --- | --- |
| Conversion | Convert audio files or an entire folder with a voice model, optionally separating vocals first and mixing the accompaniment back in. | [Conversion](/docs/guide-convert) |
| Live voice conversion | Convert your voice live through the server computer's sound card; switch parameters and voices while running. | [Live voice conversion](/docs/guide-live) |
| Vocal separation | Separate vocals and accompaniment, remove reverb, separate backing vocals and use presets with multiple steps. | [Vocal separation](/docs/guide-separate) |
| Training | Go from a dataset to a voice model: slicing, pitch, features, training and an index. After changes, rerun only the steps that need it. | [Training](/docs/guide-train) |
| Model management | Import and organize voices and indexes; download demo voices, base models, separation models and required assets. | [Model management](/docs/guide-models) |

<Callout title="Hardware validation">
  RVC Next's conversion, separation, training and live voice conversion have been fully tested on CPU. The device layer for live voice conversion is tested with a simulated sound card. CUDA, DirectML, MPS and real sound cards (including ASIO and WASAPI exclusive mode) have not yet been validated on physical hardware; see [Hardware and performance](/docs/advanced-hardware).
</Callout>
