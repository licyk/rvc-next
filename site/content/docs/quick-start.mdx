RVC Next 是 [Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI)（下文称“原版 RVC”）的一体化重写。它把转换、实时变声、人声分离、训练和模型管理放进**一个应用**：一个本地服务器、一个网页界面和一个命令行工具 `rvc-next`。

本节带你从零开始：装好 RVC Next，启动网页界面，下载必需的模型，再用一个示例音色完成第一次转换。

## RVC Next 能做什么

| 功能 | 界面中的位置 | 用来做什么 |
| --- | --- | --- |
| 转换 | **转换** | 用一个音色转换音频文件或整个文件夹；可以先分离人声、转换后再加回伴奏，一次完成“翻唱” |
| 实时变声 | **实时** | 通过服务器电脑上的麦克风和输出设备实时变声，带电平表、测试音和设备掉线后的自动重连 |
| 人声分离 | **分离** | 用内置的 RoFormer 模型分离人声与伴奏、去混响、提取主唱 |
| 训练 | **训练** | 用自己的数据集训练音色：检查数据集、按阶段运行、看损失曲线、试听检查点、导出为音色 |
| 模型管理 | **模型** | 音色库、索引、底模、分离模型、所需资源的下载，以及融合音色、从检查点提取音色等工具 |

几个贯穿全应用的设计：

- **一个音色选择器、一套音色参数**：转换、实时和音色详情页用的是同一个面板，范围、默认值和说明完全一致。每个音色有一个默认预设，在哪里用都是同样的声音。
- **所有耗时操作都是任务**：转换、分离、训练、下载都进入任务队列，可以查看进度、取消、重试和查看日志，不会卡住界面。
- **数值代码是移植而非重写**：合成器、RMVPE、转换与流式处理的算法都逐行移植自原版，并用“黄金测试”在 CPU 上与原版对比结果，因此已有的 `.pth` 音色和 `added_*.index` 索引可直接使用，声音与原版一致。详见[与原版的一致性](/docs/development-parity)。
- **按内容识别模型**：导入 `.pth`、`.index`、`.zip` 时按文件内容而非文件名判断类型与版本，并自动为音色配对索引。

## 适合谁

- **想给歌曲或语音换声的用户**：只用 **转换** 和 **模型** 两个页面就够了。
- **主播、语音聊天用户**：使用 **实时** 页面，在服务器电脑上实时变声。
- **训练自己音色的用户**：**训练** 页面把原版的各个步骤整理成可单独重跑的阶段。
- **原版 RVC 的老用户**：可以直接读取原版安装中的音色和资源，见[从原版 RVC 迁移](/docs/advanced-migrate)。
- **喜欢命令行或要批处理的用户**：每个界面操作都有对应的 `rvc-next` 命令，见[命令行](/docs/cli)。

## 快速开始的路线

1. [安装](/docs/installation)：准备独立的 Python 环境，先装适合你硬件的 PyTorch，再装 RVC Next。
2. [首次启动](/docs/first-run)：运行 `rvc-next webui`，下载 HuBERT 和 RMVPE，获取一个示例音色，完成第一次转换。
3. 之后按需阅读[使用教程](/docs/guide)：先看[界面总览](/docs/guide-interface)，再看你要用的页面。
