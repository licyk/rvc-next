icon: Compass

<Cards>
<Card title="从原版 RVC 迁移">
复用原版 RVC 的 `assets` 文件夹、直接读取原版的音色和索引、导入音色和实验，以及与原版行为的差异和逐位一致的部分。
</Card>
<Card title="远程访问与安全">
绑定地址和端口、访问令牌、远程浏览器能做和不能做的事、来源检查，以及实时变声为什么总是使用服务器的音频设备。
</Card>
<Card title="嵌入到其他程序">
在自己的 Python 程序里启动服务端和网页界面：数据目录与配置目录分开、固定设置、路径前缀，以及挂载到已有的 FastAPI 应用。
</Card>
<Card title="硬件与性能">
设备与精度的选择规则、CUDA Graph、DirectML 和 MPS、显存管理与 **释放显存**、显存不足的处理、GPU 任务排队，以及实时变声的延迟与块长。
</Card>
<Card title="常见问题">
缺少资源、CPU 上转换慢、实时变声没有设备或有爆音、端口被占用、看不到其他磁盘、结果保存在哪里等问题的解答。
</Card>
</Cards>

命令行的设置项和环境变量见 [配置与环境变量](/docs/cli-config)；界面上的设置见 [设置](/docs/guide-settings)。
