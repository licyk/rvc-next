这一部分逐页讲解 RVC Next 网页界面的用法。如果你还没有安装或启动过 RVC Next，请先阅读[快速开始](/docs/quick-start)。每个页面也都有对应的 `rvc-next` 命令，见[命令行](/docs/cli)。

## 先读这两页

**[界面总览](/docs/guide-interface)**：导航栏、顶部栏中的任务、显存和主题按钮，页面底部固定的操作栏，以及在所有页面通用的任务卡片和结果列表。读完它，其余页面的共同部分就不用再重复学习了。

**[音色参数](/docs/guide-parameters)**：音高、共振峰、音高算法、索引强度、辅音保护、响度匹配和说话人的含义、范围、默认值和调节建议，以及如何保存预设、为音色设置默认参数。**转换**、**实时**和音色详情页用的是同一个参数面板，这一页对它们都适用。

## 各个页面

**[转换](/docs/guide-convert)**（导航栏中的 **转换**）：把音频文件或整个文件夹转换成选定音色的声音。输入可以是拖入的文件、服务器上的文件或文件夹、以及之前的结果；可选步骤中可以先分离人声、再加回伴奏，一次完成整首歌的翻唱；还可以选择输出格式和采样率。先用 **预览 15 秒** 试听，再正式转换。

**[实时变声](/docs/guide-live)**（导航栏中的 **实时**）：通过服务器电脑上的麦克风和输出设备实时变声。页面上有设备面板（输入、输出、监听、电平表和测试音）、音色和参数（拖动时即时生效），以及控制延迟与稳定性的 **缓冲与降噪** 设置。运行时，顶部栏会一直显示一个实时状态标签。[在其他程序中使用实时变声](/docs/guide-live-routing) 讲解如何在 Windows、macOS 和 Linux 上通过虚拟声卡把转换后的声音送进 Discord、Zoom、OBS 或游戏。

**[人声分离](/docs/guide-separate)**（导航栏中的 **分离**）：用内置的 RoFormer 模型把歌曲分成人声与伴奏，或者去除混响、分出主唱与和声；串联预设可以一次完成多个步骤。结果按源文件分组，任一分轨都可以直接送去转换。

**[训练](/docs/guide-train)**（导航栏中的 **训练**）：用自己的数据集训练音色。每个实验按 **数据集**、**设置**、**运行**、**结果** 四步组织；运行分为清理、切片、音高、特征、训练、索引六个阶段，可以单独重跑，修改输入后相关阶段会标记为过期。训练过程中可以看损失曲线，随时试听检查点并导出为音色。

**[模型管理](/docs/guide-models)**（导航栏中的 **模型**）：分为 **音色**、**底模**、**分离模型**、**资源**、**工具** 五个标签页。在这里导入 `.pth`、`.index`、`.zip`，为音色附加索引，读取原版 RVC 安装中的音色，下载 HuBERT、RMVPE、底模、分离模型和示例音色，以及融合两个音色或从训练检查点提取音色。

**[设置](/docs/guide-settings)**（导航栏底部的 **设置**）：语言、服务器地址与端口、访问令牌、计算设备与精度、音频驱动、各个文件夹的位置、下载仓库与端点、训练默认值和外观。

## 常见任务从哪里开始

| 我想…… | 去看 |
| --- | --- |
| 给一段语音换声 | [转换](/docs/guide-convert) |
| 给一首歌换声并保留伴奏 | [转换 › 先分离人声](/docs/guide-convert#optional-steps) |
| 只要歌曲的人声或伴奏 | [人声分离](/docs/guide-separate) |

| 声音太尖/太闷、有电音、咬字不清 | [音色参数](/docs/guide-parameters) |
| 导入下载来的模型 | [模型管理](/docs/guide-models) |
| 训练自己的音色 | [训练](/docs/guide-train) |
| 使用原版 RVC 里已有的模型 | [从原版 RVC 迁移](/docs/advanced-migrate) |
