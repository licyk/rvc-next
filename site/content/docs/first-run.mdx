## 启动网页界面

在激活了 RVC Next 环境的终端中运行：

```bash
rvc-next webui
```

服务器启动后，终端会打印一行类似：

```text
SERVER_READY url=http://127.0.0.1:7868
```

稍后浏览器会自动打开这个地址。默认端口是 **7868**（与原版 RVC 的 7865 错开）。要停止服务器，在终端中按 <kbd>ctrl</kbd>+<kbd>c</kbd>。

`rvc-next webui` 的常用选项：

| 选项 | 作用 |
| --- | --- |
| `--port <端口>` | 首先尝试的端口，默认读取设置（7868）；`0` 表示任选一个空闲端口 |
| `--strict-port` / `--no-strict-port` | 端口被占用时直接失败，而不是自动尝试下一个端口（默认会尝试下一个，并提示实际使用的端口） |
| `--open` / `--no-open` | 是否自动打开浏览器（默认打开，可在设置中修改） |
| `--host <地址>` | 监听的地址，默认 `127.0.0.1`，即只允许本机访问 |
| `--data-dir <文件夹>` | 本次使用的数据文件夹 |
| `--debug` | 输出调试日志 |

<Callout type="warn" title="让其他电脑访问">

如果把 `--host` 设为 `0.0.0.0` 等非本机地址，服务器会被局域网中的其他设备访问到。为安全起见，此时必须先设置访问令牌，否则 `rvc-next webui` 会拒绝启动并提示 `rvc-next config set server.access_token <secret>`。详见[远程访问与安全](/docs/advanced-remote)。

</Callout>
网页打开后，你会看到左侧的导航栏（窄窗口下在底部）：**转换**、**实时**、**分离**、**训练**、**模型**，以及最下方的 **设置**。第一次打开时显示 **转换** 页面；之后会回到你上次所在的页面。界面各部分的说明见[界面总览](/docs/guide-interface)。

## 数据文件夹

设置、数据库、音色库、训练实验、转换结果和下载的模型都保存在一个**数据文件夹**里：

| 系统 | 默认位置 |
| --- | --- |
| Windows | `%APPDATA%\rvc-next` |
| macOS | `~/Library/Application Support/rvc-next` |
| Linux | `$XDG_DATA_HOME/rvc-next`；未设置 `XDG_DATA_HOME` 时为 `~/.local/share/rvc-next` |

设置环境变量 `RVC_NEXT_DATA_DIR` 可以换到别的位置（`rvc-next webui --data-dir` 也能指定）。`rvc-next doctor` 会显示当前使用的数据文件夹，**设置 › 关于** 中也能看到。

文件夹中主要有：

| 内容 | 说明 |
| --- | --- |
| `settings.toml` | 设置文件（`rvc-next config path` 打印它的路径） |
| `rvc-next.db` | 数据库：音色库的缓存、任务和结果的记录 |
| `models/` | 音色库（`models/voices/<音色>/`）、底模、分离模型等 |
| `assets/` | 下载的 HuBERT、RMVPE、底模和分离模型权重 |
| `experiments/` | 训练实验 |
| `outputs/` | 转换和分离的结果，按日期和任务分文件夹 |
| `jobs/` | 每个任务的日志 |

音色、实验、结果和资源的文件夹都可以在 **设置 › 存储** 中改到别处。更多配置方式见[配置与环境变量](/docs/cli-config)。

## 下载 HuBERT 和 RMVPE

转换需要两个基础模型：

- **HuBERT**（约 180 MB）：提取语音内容特征，每次转换都需要；
- **RMVPE**（约 173 MB）：默认的音高算法，转换带音高引导的音色时需要。

另外还有几个可选的音高模型，只有在音高算法中选了对应算法时才需要：**FCPE**（约 41 MB）、**CREPE**（约 85 MB）和 **CREPE tiny**（约 2 MB）。`pm` 和 **SwiftF0** 不需要下载任何文件（SwiftF0 的小模型随 RVC Next 一起提供）。

你可以任选一种方式下载：

<Tabs items={["在需要时下载", "在模型 › 资源中下载", "命令行"]}>
<Tab value="在需要时下载">

RVC Next 不会让你在缺少模型时碰到报错。只要页面上的操作需要某个尚未下载的模型，原本的按钮就会被替换成一行提示，例如“**需要 HuBERT, RMVPE**”，旁边是 **下载（353 MB）** 按钮。点一下就开始下载，进度条显示在原处，下载完成后按钮自动恢复。

</Tab>
<Tab value="在模型 › 资源中下载">

1. 点击导航栏的 **模型**，切换到 **资源** 标签页。
2. 在 **转换** 分组中点 **下载全部转换文件**，或在 HuBERT、RMVPE 各自那一行点 **下载**。
3. 每行会显示下载进度、已下载/总大小、速度和剩余时间；完成后状态变为 **已安装**。

已安装的文件可以点 **校验**，按 SHA-256 重新检查。

</Tab>
<Tab value="命令行">

```bash
rvc-next assets download          # 不带参数时下载 HuBERT 和各音高模型（约 485 MB）
rvc-next assets list              # 查看每个资源的状态
```

</Tab>
</Tabs>
下载支持断点续传，失败会自动重试，完成后会校验 SHA-256。默认从 Hugging Face 上的 [licyk/rvc-model](https://huggingface.co/licyk/rvc-model) 仓库下载；如果访问 Hugging Face 不方便，可以在 **设置 › 下载** 中把 **下载端点** 改为 **hf-mirror.com**，或者用命令行：

```bash
rvc-next assets download --source hf-mirror
```

<Callout type="idea" title="已经装过原版 RVC？">

可以直接复用原版 `assets/` 中已下载的模型，不必重复下载。做法见[从原版 RVC 迁移](/docs/advanced-migrate)。

</Callout>
## 获取一个示例音色

音色库一开始是空的。RVC Next 可以一键下载 RVC 官方的示例音色（连同索引），用来试用：

<Tabs items={["网页界面", "命令行"]}>
<Tab value="网页界面">

1. 点击 **模型**，切换到 **资源** 标签页，滚动到 **示例音色** 分组。
    - 如果你在 **音色** 标签页看到“还没有音色”，点其中的 **获取示例音色** 按钮也会跳到这里。
2. 每行显示采样率、版本、是否 **含索引** 和大小。在想要的音色那一行点 **下载**，或点分组右上角的 **全部下载**。
3. 下载完成后，这一行显示 **已安装**，并出现 **已在音色库** 按钮，点它可以打开该音色的详情页。音色同时出现在 **模型 › 音色** 中。

</Tab>
<Tab value="命令行">

```bash
rvc-next model catalog            # 列出可下载的示例音色及其 ID
rvc-next model download kikiv1    # 下载一个
rvc-next model download --all     # 下载全部尚未下载的
```

</Tab>
</Tabs>
目前目录中有 `kikiV1`、`keruanV1`、`guanguanV1`（v1，40 kHz）、`zhanzhanv2-xi`（v2，40 kHz）和 `youzhanv2-xi`（v2，48 kHz，官方没有发布它的索引）。

你自己的 `.pth` 模型可以直接拖到 **模型 › 音色** 顶部的导入区域，详见[模型管理](/docs/guide-models)。

## 完成第一次转换

1. 点击导航栏的 **转换**。
2. 在 **输入** 区域，把一个音频文件拖到“将音频文件拖放到这里”，或点击它选择文件。支持 WAV、FLAC、MP3、M4A、OGG 等格式。文件会上传到服务器，上传完成后可以点左侧的播放按钮试听。
3. 点击音色选择框（显示“选择音色”），在弹出的列表中选中刚下载的示例音色。选择框下方会显示它的采样率、版本以及是否有 **音高引导**。
4. 调整 **音色参数**。第一次只需要关注 **音高**：
    - 男声转女声音色，一般设为 **+12** 左右；女声转男声音色，设为 **−12** 左右；
    - 同性别之间转换，保持 **0** 即可。

    其他参数先保持默认，含义见[音色参数](/docs/guide-parameters)。
5. 看页面底部固定的操作栏。如果显示“**需要 HuBERT, RMVPE**”，先点 **下载**，等待完成。
6. 先点 **预览 15 秒**，只转换开头 15 秒，几秒钟就能听到效果；满意后再点 **转换** 处理整个文件。
7. 操作栏中会出现任务卡片，显示状态和进度。完成后，结果出现在 **结果** 区域：
    - 点播放按钮收听，点波形可以跳到对应位置；
    - 用 **结果 / 源音频** 切换按钮在同一位置对比转换前后；
    - 点右侧的 **更多操作**（⋮）可以 **下载** 文件。

结果文件保存在数据文件夹的 `outputs/<日期>/<任务 ID>/` 中，文件名为 `<原文件名>.<音色名>.<格式>`，例如 `song.kikiv1.wav`；预览结果的文件名带 `.preview`。

用命令行完成同样的转换：

```bash
rvc-next model list                                   # 查看音色的 ID 和名称
rvc-next convert song.wav --voice kikiV1 --pitch 12   # 音色可写 ID 或名称（不区分大小写）
rvc-next convert song.wav --voice kikiV1 --preview 15 # 只转换前 15 秒
```

<Callout type="idea" title="转换一首歌">

直接转换带伴奏的歌曲效果通常不好。在 **转换** 页展开 **可选步骤**，打开 **先分离人声** 和 **加回伴奏**，就能一次完成“分离人声 → 转换 → 混回伴奏”。详见[转换](/docs/guide-convert)。

</Callout>
