大多数选项改动后立即保存，并提示 **设置已保存**；**存储** 标签页中的文件夹需要点 **保存**。少数选项（服务器地址、端口）要到下次启动服务器时才生效，界面上会注明。

## 设置保存在哪里

- 服务器的设置保存在数据文件夹的 `settings.toml` 中。数据文件夹默认为：
    - Windows：`%APPDATA%\rvc-next`
    - macOS：`~/Library/Application Support/rvc-next`
    - Linux：`~/.local/share/rvc-next`（或 `$XDG_DATA_HOME/rvc-next`）

    可以用环境变量 `RVC_NEXT_DATA_DIR` 或 `rvc-next webui --data-dir` 指定其他位置。`rvc-next config path` 会打印设置文件的路径。

- **外观** 和 **常规 › 语言** 属于界面偏好：它们保存在服务器上（换个浏览器打开也一样），同时在浏览器本地保留一份副本，不写入 `settings.toml`。

<Callout type="info" title="由环境变量设置的值">

每个设置都可以用 `RVC_NEXT_<分组>__<字段>` 形式的环境变量覆盖，例如 `RVC_NEXT_SERVER__PORT=8000`、`RVC_NEXT_PATHS__ASSETS_DIR=D:\rvc-assets`。环境变量的优先级高于 `settings.toml`：界面上显示的是最终生效的值；在界面上修改会写入 `settings.toml`，但只要环境变量还在，生效的仍是环境变量的值。**存储** 标签页中被环境变量固定的文件夹会标注 **由环境变量设置**。完整列表见 [配置与环境变量](/docs/cli-config)，或运行 `rvc-next env`。

</Callout>
## 常规

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| **语言** | **自动（…）** | 界面语言：自动跟随系统，或固定为 English / 简体中文。立即生效 |
| **服务器启动时打开浏览器** | 开 | 运行 `rvc-next webui` 时自动打开网页。命令行的 `--open/--no-open` 可以临时覆盖 |
| **服务器地址** | `127.0.0.1` | 服务器监听的地址。**下次启动服务器时生效。** |
| **端口** | `7868` | 服务器端口，下次启动时生效。端口被占用时会自动尝试下一个端口 |

### 访问令牌

访问令牌用来保护服务器：设置之后，每个访问服务器 API 的请求（包括网页本身发出的请求）都必须带上它。

1. 在 **访问令牌** 输入框中输入一个足够长的随机字符串。
2. 点 **设置令牌**。左侧标签会变成 **已设置访问令牌**。
3. 浏览器之后会弹出 **访问令牌** 对话框（**此服务器需要访问令牌。**），输入同一个令牌即可继续使用。

要取消，点 **清除令牌**。令牌保存后不会再显示出来。

<Callout type="warn" title="让其他电脑访问之前，必须先设置令牌">

默认地址 `127.0.0.1` 只允许本机访问。把 **服务器地址** 改成 `0.0.0.0` 或局域网 IP 之后，如果没有设置访问令牌，服务器会拒绝启动。设置了令牌后，远程浏览器也才可以浏览服务器上的文件。详见 [远程访问与安全](/docs/advanced-remote)。

</Callout>
## 计算

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| **设备** | **自动** | 用哪个设备运行模型。下拉框列出检测到的设备及显存，不满足要求的设备标有 ✕。自动时选择最合适的 NVIDIA 显卡（计算能力最高、显存最大），没有时尝试 DirectML，再没有就用 CPU。也可以固定为某张显卡（`cuda:N`）、DirectML、CPU，或实验性的 Apple MPS（`mps`） |
| **精度** | **自动** | **自动** / **fp32** / **fp16**。自动时在支持的显卡上用半精度（fp16），否则用 fp32，规则与原版相同 |
| **转换时使用 CUDA Graph** | 关 | 离线转换时用 CUDA Graph 减少 GPU 调度开销 |
| **实时转换使用 CUDA Graph** | 开 | 实时变声时使用 CUDA Graph |
| **空闲多少分钟后卸载模型（0：从不）** | 10 | 模型闲置超过这么久后自动卸载，释放显存。0 表示从不自动卸载 |
| **同时运行的 GPU 任务数** | 1 | 1–16。显存充足时可以调大，让多个转换/分离任务并行 |

下方的表格列出每个设备的编号、名称、将使用的精度，以及不能使用时的原因。

修改设备、精度或 **转换时使用 CUDA Graph** 后，服务器已加载的模型会被卸载，下一个任务按新设置重新加载。实时变声在自己的后台进程中运行，它在进程启动时读取这些设置；如果改了之后实时变声没有变化，重启一次服务器即可。

## 音频

这里的设备面板与 **实时** 页面上的完全相同，两处修改的是同一份设置，用法见 [实时变声](/docs/guide-live) 的“音频设备”一节。

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| **启用 ASIO 驱动（Windows）** | 关 | 在设备列表中加入 ASIO 驱动（需要声卡提供 ASIO 驱动）。开启后到 **实时** 页面点 **刷新设备** |
| **自动重新连接丢失的设备** | 开 | 实时变声运行中设备断开时，每 2 秒重新查找，设备回来后自动恢复；关闭后设备一断开就停止 |
| **停止时显示输入电平** | 开 | 实时变声未运行时，设备面板也打开麦克风显示 **输入电平**。如果不希望麦克风一直被占用，可以关闭 |
| **输入与输出菜单列出所有设备** | 关 | 打开后，**输入** 菜单也列出输出设备，**输出** 和 **监听** 菜单也列出输入设备，用于把声音送到输入设备（例如虚拟声卡的录音端）这类特殊用途。来自另一方向的设备排在后面，并标有 **输入设备** 或 **输出设备**。驱动不支持该方向时，设备面板会在 **开始** 之前报告问题 |

## 存储

### 文件夹

| 选项 | 留空时的位置 | 存放内容 |
| --- | --- | --- |
| **音色** | `<数据文件夹>/models` | 音色库、导入的底模、分离模型、未分配的索引 |
| **实验** | `<数据文件夹>/experiments` | 训练实验 |
| **结果** | `<数据文件夹>/outputs` | 转换和分离的结果 |
| **资源** | `<数据文件夹>/assets` | HuBERT、RMVPE、底模、分离模型等下载的文件 |

每个输入框下方会显示 **默认：\{实际路径\}**。留空表示使用数据文件夹中的默认位置。

- **资源** 文件夹采用与原版 RVC 相同的布局，所以可以直接指向原版 RVC 安装里的 `assets` 文件夹，复用已经下载好的 HuBERT、RMVPE 和底模，不必重复下载。
- 修改文件夹不会自动搬移已有的文件。如果要换位置，请先自己把文件夹移过去，再修改设置。

### 浏览器可打开的文件夹

**浏览器可打开的文件夹** 决定网页上的 **服务器文件**、**浏览…** 对话框能看到服务器上的哪些位置，每行一个路径。

留空时（默认）包括：你的主目录、已添加的原版 RVC 安装、数据文件夹，以及每个驱动器（Windows 的 `C:\`、`D:\`…）或挂载的卷（macOS 的 `/Volumes/…`，Linux 的 `/media/<用户>/…`、`/run/media/<用户>/…`、`/mnt/…`）。输入框的灰色占位文字就是当前实际生效的列表。填写后则只允许这些文件夹。

<Callout type="info">

无论这里怎么设置，只有在服务器本机打开网页，或服务器设置了访问令牌时，才能浏览服务器文件。

</Callout>
### 结果保留天数

**结果保留天数（0：一直保留）**，默认 0。设为正数后，早于这么多天的转换/分离结果会被自动删除。

改完文件夹或可浏览的文件夹后，点右下角的 **保存**。

## 下载

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| **模型仓库** | `licyk/rvc-model · 为 rvc-next 整理，含示例音色` | 模型文件从哪个 Hugging Face 仓库下载 |
| **下载端点** | **Hugging Face** | 通过哪个地址访问仓库：**Hugging Face**、**hf-mirror.com** 或 **自定义** |
| **自定义地址** | — | 选 **自定义** 时出现，填写镜像站地址 |
| **校验文件** | 开 | 下载完成后核对 SHA-256，发现损坏会标记为 **校验不符** |

两个模型仓库：

- **licyk/rvc-model**（默认）：为 rvc-next 整理，按类别收录了 rvc-next 用到的全部模型，还包含示例音色。
- **lj1995/VoiceConversionWebUI**：RVC 官方仓库，模型相同，但没有示例音色。

正如界面上的说明：**rvc-model 按类别收录 rvc-next 用到的全部模型，并包含示例音色。官方仓库模型相同但没有示例音色；示例音色始终从 rvc-model 下载。** 所选仓库缺少某个文件时，会自动从另一个仓库获取。

<Callout type="idea" title="在中国大陆下载慢？">

把 **下载端点** 改为 **hf-mirror.com** 通常会快很多。命令行也可以临时指定：`rvc-next assets download --source hf-mirror`（会同时保存到设置）。

</Callout>

| 选项 | 默认值 |
| --- | --- |
| **采样率** | 40k（可选 32k / 40k / 48k） |
| **模型版本** | v2（可选 v1 / v2） |
| **轮数** | 20 |

| **音高引导** | 开 |
| **将数据集缓存到显存** | 关 |

## 外观

| 选项 | 可选值 | 说明 |
| --- | --- | --- |
| **主题** | **浅色** / **深色** / **跟随系统** | 默认跟随系统 |
| **颜色** | 6 个色块 | 整个界面的主色调，配色会根据所选颜色自动生成 |
| **对比度** | **标准** / **中** / **高** | 提高文字与背景的对比度 |

## 在命令行中修改设置

所有设置也可以在命令行中查看和修改，改动会写入同一个 `settings.toml`：

```bash
rvc-next config show                          # 显示生效的设置
rvc-next config get server.port               # 查看某一项
rvc-next config set server.port 8000          # 修改某一项（JSON 会被解析）
rvc-next config set server.access_token null  # null 表示清除
rvc-next config path                          # 设置文件的位置
```

详见 [配置与环境变量](/docs/cli-config)。
