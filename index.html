RVC 的全部工作，收进同一个应用

RVC Next 用一个服务端、一个网页界面和一套命令行完成音色转换、实时变声、人声分离、模型训练与模型管理；数值计算从原版逐行移植，输出与原版一致。

WORKFLOW

从安装到第一个属于你的音色

四步走完整个流程，每一步在网页界面和命令行中都有对应做法。

  1. 01

    安装

    在独立的 Python 环境中先装 PyTorch，再用 pip 安装 RVC Next。

  2. 02

    下载模型

    首次使用时一键下载 HuBERT 与音高模型，再挑一个示例音色。

  3. 03

    转换与实时变声

    选择音色、调整音高，转换音频文件，或接上麦克风实时变声。

  4. 04

    训练自己的音色

    准备录音，运行训练，试听检查点，满意后导出到音色库。

WHY RVC NEXT

与原版一致，用起来更省心

保留原版的数值结果与模型格式，把重复劳动交给程序处理。

  • 输出与原版逐位一致

    离线转换与实时变声都用对比测试与原版核对，现有模型和索引直接可用。

  • 一个服务端，网页与命令行同源

    网页界面与命令行调用同一套核心操作，命令行的 JSON 输出与 API 完全相同。

  • 实时变声可热切换

    运行中切换音色、音高算法和参数，新音色在两个音频块之间无缝换上。

  • 导入按内容识别

    无论文件名如何，都能认出音色、索引、底模与分离模型，并自动配对。

  • 训练只重跑改动部分

    每个阶段记录输入指纹，数据或设置变化时只重做受影响的步骤。
