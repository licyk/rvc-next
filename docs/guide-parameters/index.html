音色参数

音色参数 决定转换出来的声音：音高、共振峰、音高算法、索引强度、辅音保护和响度匹配，以及多说话人音色的说话人。RVC Next 在 转换、实时 和音色详情页的 默认参数 中使用同一个参数面板，名称、范围、默认值、说明和顺序完全一致；命令行和 API 也使用同一组参数和同样的范围。

本页逐一说明每个参数，并介绍预设的用法。

参数面板

面板标题为 音色参数，从上到下是：

  1. 音高算法：列出各种音高算法的菜单；
  2. 音高、共振峰、索引强度、辅音保护、响度匹配 五个滑块；
  3. 音高细节：点击展开的一节，含 无音高帧、极高音、自动定调 和 自动修音；
  4. 右上角的 预设 菜单。

每个滑块显示当前数值，下方是一行说明。值与默认值不同时，数值旁会出现 恢复默认（↺）按钮。某个参数对当前音色不起作用时，滑块会变灰，并说明原因。

面板下方的小字说明参数何时生效：

  • 在 转换 和音色详情页：“在下一次转换时生效。”，即修改后要重新点 预览 15 秒 或 转换；
  • 在 实时 页：“拖动时即时生效。”，见下文实时变声中的参数。

音高算法

如何跟踪输入的音高。

RVC 先从输入中提取每一帧的音高（F0），再让音色按这个音高（加上 音高 的偏移）发声。可选的算法：

选项特点需要下载
pm（快速）基于 Praat 的传统算法，速度最快，对 CPU 友好；对歌声、气声和嘈杂的录音容易跟错无
RMVPE（最佳）神经网络音高模型，准确度最高，抗噪能力强，适合歌声；默认选项RMVPE（约 173 MB）
FCPE轻量的神经网络音高模型，速度快，模型文件小FCPE（约 41 MB）
CREPE（平滑，较慢）许多 RVC 音色训练时用的神经网络音高算法；歌声的音高曲线平滑，但在 CPU 上大约只有实时速度CREPE（约 85 MB）
CREPE tiny（快速）CREPE 的小模型：快得多，准确度略低CREPE tiny（约 2 MB）
SwiftF0（快速）非常小、非常快的神经网络音高模型（单个 CPU 核约 100 倍实时），在其评测中与 RMVPE 相当，最高 2093 Hz；来自 Applio 的修复步骤会把它短暂读低一个八度的音抬回来无（随 RVC Next 提供）

建议：

  • 一般情况下保持 RMVPE。
  • 没有 GPU、又追求速度时，可以试试 SwiftF0、FCPE 或 CREPE tiny，或者对干净的语音使用 pm。
  • 用 CREPE 音高训练的音色（网上分享的音色中很常见）用 CREPE 可能最贴近它的训练；有 GPU 时它也足够快，可以用于实时变声。
  • 如果结果中出现突然跑调、破音、音高乱跳，多半是音高跟踪出错，换成 RMVPE 往往能解决。

所选算法对应的模型没有下载时，运行按钮会被替换为“需要 RMVPE”（或该算法的其他模型）和 下载 按钮。

无音高引导的音色（训练时关闭了音高引导）不使用音高，此时这一行会变暗，选择哪种算法都没有影响，也不需要下载音高模型。

音高

以半音为单位：+12 为升高一个八度。男声转女声约 +12。

把输入的音高整体平移若干个半音后再交给音色。这是最常调整的参数：

情况建议值
男声输入，女声音色约 +12（有时 +8 ～ +12 更自然）
女声输入，男声音色约 −12
同性别之间0，再按需要 ±1 ～ ±3 微调
翻唱时匹配原曲调按音色本身的音域，以 12 的倍数为主，避免与伴奏跑调

调整的目标是让移调后的音高落在音色训练数据的音域内。偏离太多时，声音会发虚、走音或失真。

给歌曲移调要小心

如果打开了 先分离人声 和 加回伴奏，伴奏不会跟着移调。此时 音高 最好用 0 或 ±12，否则人声会与伴奏不在一个调上。

界面中按 1 个半音调节；命令行和 API 接受小数，例如 --pitch 1.5。音高 只对有音高引导的音色起作用。

共振峰

改变声道的音色而不改变音高。

共振峰决定了声音听起来像“多大的人”在说话。正值会抬高共振峰，声音更细、更亮、更年轻；负值会降低共振峰，声音更厚、更沉。音高不变。

  • 跨性别转换时，音高 调好后声音仍然“不像”，可以把 共振峰 向同一方向小幅调整，例如男转女时 +0.5 ～ +1；
  • 调整幅度不宜过大，±2 已经是很明显的变化，过大会让声音不自然。

与原版的区别

原版 RVC 只在实时变声中提供共振峰偏移。RVC Next 把同样的方法也用在文件转换上；共振峰 为 0 时，计算与原版完全相同。

索引强度

从音色的索引中取用多少它自身的音色特征。

音色的索引（.index 文件）保存了训练数据的特征。转换时，RVC 会在索引中查找与输入最接近的特征，按这个比例混入，让结果更像训练时的声音。

  • 越高：音色越接近训练数据，口音和咬字也更像训练者；但如果索引质量不好或数据量太少，可能带来杂音、含糊或咬字不清；
  • 越低：更多保留输入本身的发音，咬字更清楚，但音色相似度降低；
  • 0：完全不使用索引。

建议从默认的 0.75 开始；发音含糊或有杂音时降到 0.3 ～ 0.6。

如果音色没有附加索引，这个滑块会变灰，并提示“此音色没有索引，索引强度不起作用。可在“模型”中附加索引。”附加索引的方法见模型管理。多说话人音色可以为每个说话人附加单独的索引，转换时会使用所选说话人的索引。

辅音保护

在输入没有音高的地方保持呼吸声和辅音清晰；0.5 为关闭。

清辅音（如 s、sh、t、k）和呼吸声没有音高，用音色特征替换它们容易产生“电音”、撕裂声。辅音保护会在这些没有音高的位置保留更多输入本身的特征。它抑制的是索引的作用：索引强度 为 0 或音色没有索引时，它不改变任何东西。

  • 数值越小，保护越强；0.5 表示关闭保护；
  • 默认 0.33 适合大多数情况；
  • 如果齿音、呼吸声出现撕裂或电子音，降低到 0.2 ～ 0.3；
  • 保护过强（接近 0）会让这些位置更像原声，也会削弱 索引强度 的效果。

无音高引导的音色不使用这项，滑块会变灰，并提示“此音色没有音高引导，此项不起作用。”无音高帧 选为 填补（RVC 2026） 时它同样不起作用，滑块会说明这一点。

无音高帧

位于 音高细节 中。音高算法在呼吸声和清辅音中找不到音高，这一项决定这些帧如何处理：

选项--unvoiced作用
保护（默认）protect用相邻帧填补音高，并对这些帧应用 辅音保护。
无音高（经典 RVC）zero这些帧也不给音高，音色在这里发出噪声而不是乐音，与经典 RVC 和 Applio 的转换相同。网上分享的音色大多是这样训练的，用这一项可能更干净。
填补（RVC 2026）originalRVC Next 所依据的 RVC 整合包的规则：填补音高，辅音保护不起作用。

RVC 2026 在辅音保护寻找无音高帧之前就把音高填补了，所以它永远找不到，保护也就从不生效。保护 保留填补后的音高（用 RVC 2026 或 RVC Next 训练的音色需要它），但按音高算法自己的判断确定这些帧。实时变声使用同一设置。

极高音

位于 音高细节 中；只用于 RMVPE，且只在转换中生效（实时变声不提供：它会让每一块的音高分析耗时翻倍）。

RMVPE 的训练数据大约到 C6（约 1040 Hz）为止。高于这个音时，它会非常确定地报出低一个八度（或低一个八度加五度）的音，转换出的声音也就唱在那里。纠正为真实音高 会把音频降低一个八度再跑一遍 RMVPE（在那里它能读对），用这一遍把每一帧放回正确的八度；两遍一致的地方保留第一遍更精细的音高曲线。低于 460 Hz 的帧从不改动，所以说话和大多数演唱的结果与原来完全相同；音高分析耗时约为三倍。

选项--high-register作用
按检测结果（默认）off使用 RMVPE 的结果，与原版相同。
纠正为真实音高true_pitch纠正的最高音高（默认 1250 Hz）以内的音得到真实音高；更高的音保持低一个八度，因为用 RMVPE 音高训练的音色很少能发出更高的音。
纠正，但低一个八度fold只修正被读错音名的音，并写成比真实音高低一个八度，让每个音都留在音色训练过的音域内。

这个纠正方法来自 Applio。

自动定调

位于 音高细节 中；只在转换中生效（实时变声中调会随块跳动）。它计算输入的常用音高（有声帧的中位数）与音色的音高相差多少，并在 音高 之外再移调这么多：

选项--auto-pitch移调
关（默认）off不移调
到最近的半音semitone把差距取整到半音（最多两个八度）。适合说话。
按整八度octave把差距取整到整八度，歌曲保持原调。适合唱歌。

目标 是目标音高。为 0 时就是音色自己的音高：rvc-next 训练音色时会测量训练数据的中位音高，并在音色的 信息 中显示为 训练音高（中位数）。没有记录它的音色（大多数下载的音色）以 155 Hz（较低的声音）为目标；较高的声音可设为约 255 Hz。任务日志会写出选定的调。来自 Applio 的“建议音高”，它按分块计算；这里对整个文件只选一次。

自动修音

位于 音高细节 中；转换和实时变声都可用。把每个有声帧拉向 A4 = 440 Hz 调律下最近的半音：1 让每一帧都对齐到音符上（机械的“电音”效果），0.3 ～ 0.6 在保留一些颤音的同时让音准更稳，0 不改变。呼吸声和辅音不会被赋予音符。它修正的是你最终听到的音高，即经过 音高、自动定调 和 共振峰 之后的音高。

响度匹配

0 跟随输入的响度，1 保持转换后的响度。

控制输出的音量变化（响度包络）跟随谁：

  • 0：输出的音量起伏完全跟随输入，适合需要保留原有轻重、强弱表现的歌声；
  • 1：保持模型生成的响度，不做调整；
  • 默认 0.25：以输入的起伏为主。

想更多保留原声的轻重、强弱表现时调低；想让输出更接近模型自身的响度时调高。拿不准时保持默认。

说话人

多说话人音色（模型文件中带有说话人信息）在音色选择框下方会多出一个 说话人 下拉框，按名称和编号列出各个说话人。选择新音色时，会自动选中它的第一个说话人。

单说话人音色不显示这个下拉框，使用编号 0。说话人的名称可以在音色详情页中修改，见模型管理。命令行用 --speaker <编号> 指定。

预设

预设是一组保存下来的音色参数（不含说话人）。每个预设要么属于某个音色，要么是所有音色通用的。

每个音色的默认预设

  • 每个音色都有一个默认预设，导入音色时自动创建，名为 Default，初始值来自设置中的 convert.default_params（即上表中的默认值）。
  • 在任意页面选择一个音色时，参数面板会自动载入它的默认预设（说话人保持不变）。所以把常用的音高、索引强度等存进默认预设后，这个音色在 转换 和 实时 中一选即用。
  • 修改默认预设：打开 模型 › 音色，点击音色进入详情页，在 默认参数 分区中调整参数，点 保存。

应用预设

点参数面板右上角的 预设，菜单中列出：

  • 当前音色的预设，其中默认预设带“· 默认”；
  • 所有音色通用的预设，带“· 所有音色”；
  • 最后一项 保存为预设。

点一个预设即应用它的参数（说话人保持不变），屏幕底部会提示预设名称。

保存预设

  1. 调好参数后，点 预设 › 保存为预设。
  2. 在 预设名称 中输入名称。
  3. 勾选 仅用于此音色，预设只属于当前音色；取消勾选则保存为所有音色通用的预设。
  4. 勾选了 仅用于此音色 时，还可以勾选 设为此音色的默认预设，用它替换原来的默认预设。
  5. 点 保存。

界面中暂时不能删除或重命名预设，请使用命令行：

rvc-next convert 默认从音色的默认预设出发，--preset <名称> 改用其他预设，再用 --pitch 等选项单独覆盖。

实时变声中的参数

在 实时 页面，参数面板的说明变为“拖动时即时生效。”：所有音色参数（音高、共振峰、索引强度、辅音保护、响度匹配、音高细节；实时变声没有 极高音 和 自动定调）在拖动滑块时就会应用到正在进行的变声，不需要停止再启动。

  • 切换 音高算法 时，新算法的模型会在后台加载。如果它尚未下载，变声会继续使用原来的算法，并提示缺少的模型。
  • 切换 说话人 时，会同时换用该说话人的索引。
  • 切换音色同样即时生效，并会载入新音色的默认预设。
  • 实时页使用的参数会被记住，下次打开时恢复。

此外，实时页还有一组 缓冲与降噪 参数，控制延迟与稳定性：

这些参数的详细说明和调节方法见实时变声。
