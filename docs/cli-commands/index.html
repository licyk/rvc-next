命令参考

本页按命令树列出 rvc-next 的每条命令和子命令，内容来自各命令的 --help 输出。命令和子命令在帮助中按字母顺序排列，本页按用途分组。

所有命令都接受下面两个选项，表格里不再重复：

选项说明
--debug打印调试日志
--help显示帮助并退出

表中"默认值"一栏为"—"时表示不给出就不生效，或沿用预设、设置里的值（会在说明里写明）。范围写成 [a, b]。

根命令

基于检索的语音转换：转换、实时、分离和训练。

选项说明
--install-completion为当前 shell 安装补全
--show-completion显示当前 shell 的补全脚本，用于复制或自定义安装

服务器与系统

webui

启动服务器并打开 Web UI。

选项说明默认值
--host <str>绑定的地址取自设置 server.host（127.0.0.1）
--port <int>第一个尝试的端口，[0, 65535]；0 由系统任选取自设置 server.port（7868）
--strict-port / --no-strict-port端口被占用时直接失败，而不是尝试下一个端口取自设置 server.strict_port（关）
--open / --no-open在浏览器中打开 Web UI取自设置 server.open_browser（开）
--data-dir <directory>数据目录（设置、数据库、模型、结果）RVC_NEXT_DATA_DIR 或系统默认位置
--config-dir <directory>存放 settings.toml 的文件夹RVC_NEXT_CONFIG_DIR 或数据目录
--api-prefix <str>把 API、socket 和 Web UI 放到这个路径下，例如 /voice无
--ssl-certfile <file>PEM 证书：以 HTTPS 提供服务（从其他电脑在实时变声中使用 本浏览器 时需要）server.ssl_certfile
--ssl-keyfile <file>证书的私钥server.ssl_keyfile

端口被占用时依次尝试后面的端口（最多 20 个），并在日志里提示实际使用的端口；全部失败时以退出码 3 结束。绑定到非本机地址时会在日志中警告，不需要访问令牌（见 远程访问与安全）。启动成功后标准输出打印一行 SERVER_READY url=http://...。

转换与分离

convert

用一个音色转换音频文件或文件夹。参数从音色的默认预设开始，命令行给出的选项覆盖对应的值。

参数说明
INPUTS...音频文件或文件夹（必填，可多个）
选项说明默认值
-v, --voice <str>音色 id、名称或 .pth 路径（必填）—
-o, --output <directory>输出文件夹数据目录中该任务的文件夹
--preset <str>以这个预设为起点，而不是音色的默认预设音色的默认预设
--index <file>用路径给出 .pth 音色时使用的索引—
--speaker <int>多说话人音色的说话人 id，[0, 109]取自预设
--pitch <float>音高偏移（半音），[-24, 24]取自预设
--formant <float>共振峰偏移（半音），[-2, 2]取自预设
--f0 <str>音高算法：pm、rmvpe、fcpe、crepe、crepe-tiny 或 swift取自预设
--index-rate <float>索引强度，[0, 1]取自预设
--protect <float>辅音保护，[0, 0.5]；0.5 为关闭取自预设
--rms-mix <float>响度匹配，[0, 1]；1 保持转换后的响度取自预设
--unvoiced <mode>无音高帧：protect、zero 或 original，见无音高帧取自预设
--autotune <float>把音拉向最近的半音，[0, 1]；0 为关闭取自预设
--auto-pitch <mode>off、semitone 或 octave：再移调，使输入的中位音高落到目标上；见自动定调取自预设
--auto-pitch-target <float>自动定调的目标音高（Hz），[0, 1000]；0 为音色自己的，否则 155取自预设
--high-register <mode>RMVPE 约 1040 Hz 以上：off、true_pitch 或 fold，见极高音取自预设
--f0-ceiling <float>true_pitch 写入的最高音高，[1000, 2000] Hz取自预设
--separate <str>先用这个分离预设分离，再转换人声—
--remix加回伴奏（需要 --separate）关
--remix-gain <float>伴奏增益（dB）0.0
--format <str>wav、flac、mp3、m4a 或 ogg（Opus）设置 convert.output_format（wav）
--resample <int>把结果重采样到这个采样率，至少 16000音色自身的采样率
--denoise <float>对转换结果降噪，[0, 1]；0 为关闭0
--effect <spec>转换结果上的效果，可重复，按顺序处理：KIND 或 KIND:NAME=VALUE,...，例如 --effect compressor --effect reverb:room_size=0.6,wet_level=0.3；effects 列出全部效果。需要 rvc-next[effects]无
--recursive / --no-recursive进入文件夹输入的子文件夹--no-recursive
--overwrite / --no-overwrite替换输出文件夹里已有的文件--no-overwrite
--preview <float>只转换前 N 秒，[1, 120]—
--json以 JSON 打印完成的任务关

结束后逐行打印输出文件的路径。

effects

separate

分离人声、伴奏和混响。可以用单个预设，也可以用串联预设。

参数说明
INPUTS...音频文件或文件夹（不用 --list 时必填）
选项说明默认值
-p, --preset <str>预设 id；用 --list 查看设置 separation.default_preset（vocals）
-o, --output <directory>输出文件夹数据目录中该任务的文件夹
--format <str>wav、flac、mp3、m4a 或 ogg（Opus）设置 separation.output_format（flac）
--recursive / --no-recursive进入子文件夹--no-recursive
--list列出预设并退出关
--json打印 JSON关

内置预设：vocals、vocals-aggressive、dereverb、dereverb-aggressive、karaoke，以及串联预设 vocals-clean（人声 → 去混响）和 lead-clean（人声 → 主唱 → 去混响）。导入的分离模型以 user-<名称> 作为预设 id。

--base <str>底模 id（见 rvc-next model list --type base）；保存到实验中按采样率、版本和音高引导自动选择
--precision <str>auto（所有显卡都支持时用 fp16）、fp32 或 bf16；保存到实验中实验中保存的值（auto）
--tf32 / --no-tf32在 NVIDIA 显卡上使用 TF32 运算；保存到实验中实验中保存的值（关）
--checkpointing / --no-checkpointing梯度检查点：显存更少、每步更慢；保存到实验中实验中保存的值（关）
--fresh-speakers / --no-fresh-speakers使用新的说话人向量而不是底模的；保存到实验中实验中保存的值（关）
--samples / --no-samples每次保存时渲染一段训练样例；保存到实验中实验中保存的值（开）
--cut <mode>切分方式：auto（先按静音切开再切成片段）、fixed（直接按长度切）或 none（已切好）；保存到实验中实验中保存的值（auto）
--chunk-seconds <float>片段长度，[0.5, 10]；保存到实验中有 GPU 时 3.7 秒，没有时 3.0 秒
--overlap <float>片段之间的重叠（秒），[0, 0.4]；保存到实验中0.3
--highpass / --no-highpass切片前的 48 Hz 高通；保存到实验中开
--normalize <mode>响度：slice（原版）、file 或 none；保存到实验中slice
--dataset-denoise <float>切片前对每段录音降噪，[0, 1]；保存到实验中0

--epochs、--batch-size、--save-every 和 --base 会写入实验的训练设置。增加 --epochs 后，即使训练阶段已完成，不带 --stage 运行也会再次运行训练阶段。

live latency

用回环实测已保存设备的真实延迟：先把输出接回输入（音频线、虚拟声卡的回环，或把扬声器靠近麦克风）。在输出播放四段噪声，在输入中找到它们，打印实测的往返时间、转换器自身的延迟、两者之和，以及供对比的估计值。实时变声必须已停止。没有检测到返回的噪声或各段结果不一致时退出码为 1，设备无法打开时为 8。

选项说明默认值
--block-ms块长（毫秒）已保存的值
--level-db测试噪声的峰值电平，−40 到 −3 dBFS-12
--json打印 JSON关

选项说明默认值

设备名可以写完整名称或其中一部分，只要只匹配到一个设备；匹配到多个时请改用 live devices 中的 id。启动后，所用的设备、缓冲参数、音色和参数会保存为下次的默认值。
